# E-Commerce Customer Behaviour Analysis Using Machine Learning

## Project Description

This project focuses on analyzing e-commerce customer behavior and predicting customer purchase intention using machine learning techniques. The dataset was analyzed, cleaned, preprocessed, and modeled using classification algorithms such as Logistic Regression and Random Forest Classifier.

The project applies data science techniques to identify patterns in customer purchasing behavior and generate insights that can help businesses improve customer engagement, marketing strategies, and sales performance.

The project includes:
- Exploratory Data Analysis (EDA)
- Data preprocessing
- Feature engineering
- Model training
- Hyperparameter tuning
- Model evaluation
- Feature importance analysis
- Streamlit web application

# Project Overview

The objective of this project is to analyze customer purchasing behavior in e-commerce platforms and build a predictive machine learning model that classifies whether a customer is likely to make a purchase.

The project uses:
- Customer demographic information
- Advertisement interaction
- Social media influence
- Purchase amount
- Customer engagement data

to predict purchase intention.
